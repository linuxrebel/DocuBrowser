Then build a macOS .dmg installer for DocuBrowse FOSS. Work quietly — no narration between steps, just do it. Here are the requirements:

## What to build

packaging/macos/build_macos_dmg.sh — a build script (run from repo root) that produces dist/docubrowser-foss-<version>.<release>-macos.dmg

The .dmg should contain a folder (or direct layout) with:
- An Install.command script (double-clickable in Finder) that:
  - Runs preflight checks: python3 >= 3.9, python3 -c "import venv", python3 -c "import ensurepip"
  - Installs to ~/Applications/DocuBrowse/ (no sudo required)
  - Creates a Python virtualenv there, pip installs requirements.txt
  - Creates CLI wrapper scripts in /usr/local/bin/docubrowser and /usr/local/bin/docuback (with sudo, or falls back to ~/bin/ if user declines)
  - Creates a macOS .app bundle at ~/Applications/DocuBrowse/DocuBrowse.app that launches "docubrowser start && docubrowser open" in Terminal
  - The .app bundle should use icons/icon-512.png converted to an .icns file (use sips + iconutil, which are built into macOS)
  - Prints post-install instructions mentioning Ollama prerequisite
- An Uninstall.command script that removes ~/Applications/DocuBrowse/, the CLI wrappers, and the .app bundle (preserves ~/.docubrowser/ user data)

## Key constraints

- Follow the same APP_FILES list used by build_packages.sh and build_windows_zip.sh (the canonical set of files to include)
- platform_paths.py already handles macOS paths correctly (it uses the Linux/Unix code path: ~/.docubrowser/ for user data, /var/run or ~/.local/run for PID files, /var/log or ~/.local/var/log for logs)
- Version is extracted from docubrowser.py (same pattern as build_windows_zip.sh)
- Release number auto-detection same pattern as build_windows_zip.sh
- The build script should work on macOS (use hdiutil to create the .dmg)
- Include EndUser_docs/ and icons/ directories
- Prune dist/ to keep latest 2 macOS dmgs (same pattern as other build scripts)
- Do NOT use any third-party tools — only things built into macOS (hdiutil, sips, iconutil, etc.)
