  Categorizes duplicates by directory
  Identifies hotspots: Companies/, ClickCharts/, Backups/, Archives/
  Tracks metadata for each duplicate instance

STEP 4: CANONICAL SELECTION
  For each duplicate group, selects "keeper" version:
    1. Prefer deepest directory path (most specific location)
    2. If equal depth, prefer most recent modification time
    3. Flag archive/backup versions for removal

TECHNICAL SPECIFICATIONS
================================================================================

HASH ALGORITHM
  - SHA256 (cryptographically secure, collision-resistant)
  - Sample size: First 5000 bytes (fast, accurate for most files)
  - Full-file hashing available if needed for verification

FILENAME MATCHING
  - Library: difflib.SequenceMatcher
  - Threshold: 0.8 (80% similarity)
  - Comparison: File stems only (ignores extensions)
  - Examples:
    * "report.pdf" and "report-final.pdf" -> 0.87 (match)
    * "data.xlsx" and "data_v2.xlsx" -> 0.82 (match)
    * "file1.txt" and "file2.txt" -> 0.67 (no match)

SCALABILITY
  - Linear time: O(n) for initial hash computation
  - Hash lookups: O(1) average case
  - Memory: ~1MB per 1000 files
  - Throughput: ~10,000 files per minute

ERROR HANDLING
  - Permission denied: Skip file, log error
  - Broken symlinks: Skip with error count
  - Large files (>1GB): Still hashable via sample
  - Read-only filesystems: Scan-only capability

DEPENDENCIES
  - Python 3.6+
  - Standard library only (no external packages)
  - Platform: Linux, macOS, Windows compatible
