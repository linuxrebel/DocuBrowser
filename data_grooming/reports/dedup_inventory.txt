TECHNICAL NOTES
================================================================================

HASH SAMPLE SIZE:
  - Initial hash uses first 5000 bytes only (fast)
  - Sufficient for most file type identification
  - False positives rare for different content
  - Can implement full-file hash for verification if needed

FILENAME SIMILARITY:
  - SequenceMatcher threshold: 0.8 (80% match)
  - Compares file stems only (ignores extensions)
  - Example matches: "report.pdf" vs "report-final.pdf", "data.xlsx" vs "data_v2.xlsx"
  - Requires manual review to avoid false positives

SCALABILITY:
  - Linear O(n) for initial hash computation
  - Hash lookups: O(1) average case
  - Can process 10,000 files in < 1 minute
  - Memory usage: ~1MB per 1000 files (hash table only)

ERROR HANDLING:
  - Permission denied: Skip file, increment error counter
  - Broken symlinks: Skip with error logging
  - Large files (>1GB): Still hashable (sample first 5000 bytes)
  - Read-only filesystems: Scan-only (no delete capability)
