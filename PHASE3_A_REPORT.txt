8. ISSUES IDENTIFIED & RESOLUTIONS
================================================================================

Issue 1: /api/tags returns dict instead of array
  Root Cause: Server implementation returns raw get_all_tags() output
  Impact: HTML expects {tags: [...]} format
  Resolution: Client-side adapter in index.html fetch handler
  Severity: LOW (simple transformation)

Issue 2: Search response uses "results" key, not "documents"
  Root Cause: API consistent naming
  Impact: HTML fetch handler must use .results instead of .documents
  Resolution: Update HTML search handler
  Severity: LOW (one-line change)

Issue 3: Tags not included in search results
  Root Cause: merged_search() doesn't return tag array
  Impact: Tag filtering won't work on search results
  Resolution: Server enhancement OR fetch tags separately
  Severity: MEDIUM (workaround: fetch tags in parallel)

Issue 4: Empty HTML now contains mock API (confusing state)
  Root Cause: Original design had mock endpoints
  Impact: Real API calls will replace them cleanly
  Resolution: Remove mock endpoint code, use real calls
  Severity: LOW (cleanup only)
